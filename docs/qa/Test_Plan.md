# StreetBite V1.0 — Test Plan

## Scope

In scope: Splash, Onboarding, Login, Sign Up, Home, Browse, Restaurant, Meal Details, Cart, Checkout, Add Card, Delivery Address, Orders, Order Tracking, Profile, Vendor Map, localization, theme.

Out of scope: real payment gateway settlement, production Firebase App Check, iOS TestFlight.

## Test types

- GUI / visual vs UI kit
- Positive functional
- Negative / validation
- Mobile (rotation, back, kill/relaunch, offline cache)

## Entry criteria

App installs on a physical Android device; demo or Firebase credentials available; network on.

## Exit criteria

- All P0 cases executed
- No open Blocker/Critical bugs
- Traceability matrix complete
- Test closure summary signed

## Environments

- Emulator: Pixel 5 API 34
- Physical: Android 13+ handset
